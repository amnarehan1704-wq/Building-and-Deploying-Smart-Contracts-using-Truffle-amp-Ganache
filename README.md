## Idea
Assignment 2 (Campus Lost & Found) is now deployed with the **Truffle Suite** on a **local Ganache blockchain**
instead of Remix. Students report lost/found items on-chain, another student claims an open item, and the
reporter confirms the return. Lifecycle: `Open -> Claimed -> Returned`.

**Bonus (2 contracts):** `Reputation.sol` is a second contract. When an item is marked returned,
`SmartContract.sol` calls it to give the helper (claimer) 1 reputation point.

## Setup and Commands
```bash
# 1) install Truffle, Ganache and test helpers (listed in package.json)
npm install

# 2) TERMINAL 1 - start the local blockchain (keep it running)
npx ganache --port 7545 --wallet.deterministic --chain.chainId 1337 --chain.networkId 5777
#    (Ganache GUI also works: RPC http://127.0.0.1:7545, chain id 1337)

# 3) TERMINAL 2
npx truffle compile              # compile contracts -> build/contracts
npx truffle test                 # run the 14 tests
npx truffle migrate --reset      # deploy both contracts (run this LAST, it writes frontend/contract-config.js)
npx truffle exec scripts/interact.js --network development   # optional CLI demo
```
> Run `truffle test` **before** the final `truffle migrate --reset`, because tests deploy their own copies
> and the last migration decides which addresses the frontend uses.

### Run the frontend
```bash
npm run frontend       # same as: python -m http.server 8000 --directory frontend
```
Open http://localhost:8000

1. In MetaMask add the Ganache network (the page also offers to add it automatically):
   - RPC URL: `http://127.0.0.1:7545`  - Chain ID: `1337`  - Symbol: `ETH`
2. Import 2 Ganache accounts into MetaMask using their private keys (printed by Ganache).
3. Click **Connect MetaMask**, report an item, confirm the transaction.
4. Switch to the 2nd account -> **Claim**. Switch back to the reporter -> **Mark as Returned**.
   The helper's reputation points increase.

## How to test the project
- Automated: `npx truffle test` -> expected result `14 passing`.
- Manual (console): `npx truffle console`
```js
let app = await CampusLostFound.deployed()
await app.reportItem("ID card", "FAST card", "Cafeteria", false)
(await app.getItemCount()).toString()
await app.getItem(1)
```

## Contract Functions
| Function | Type | Description |
|---|---|---|
| `reportItem(title, description, location, isLost)` | write | Report a lost or found item |
| `claimItem(id)` | write | Claim an open item (reporter cannot claim own item) |
| `markReturned(id)` | write | Reporter confirms return; claimer gets a reputation point |
| `getItemCount()` / `getItem(id)` | read | Read items |
| `Reputation.getPoints(address)` | read | Helper points of a student |
